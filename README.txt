# Shaikh Alfiya Portfolio Website

A premium, responsive resume/portfolio website built with plain HTML, CSS and JavaScript.

## Files
- index.html — website structure/content
- style.css — design and responsive styling
- script.js — menu, animations and interactions
- assets/Shaikh-Alfiya-Resume.pdf — add your actual resume PDF here

## Run locally
Open `index.html` in a browser.

## Free hosting with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Go to Settings → Pages.
5. Select Deploy from a branch → main → root.
6. Save.
7. Your free site will be available at:
   https://YOURUSERNAME.github.io

No Framer branding is used.
